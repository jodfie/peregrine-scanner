# peregrine-scanner

This repository archives Raven scanner manuals, drivers, support articles, and related tools for offline analysis and preservation.

## Archived Raven downloads

The canonical list of currently downloaded assets (manuals, drivers, site snapshots, etc.) is kept in:

- `docs/raven-download-inventory.txt`

That file is regenerated as new assets are added via `scripts/fetch-raven-archive.sh` or manual curation.

## Community-sourced Raven Pro extras

In addition to files pulled directly from raven.com and official storage buckets, this repo includes Raven Pro assets sourced from a community Google Drive bundle referenced on Reddit:

- Additional Raven Pro Windows TWAIN driver and Virtual Scanner Link installers:
  - `downloads/drivers/pro/AN360W_V620_20191106/`
  - `downloads/drivers/pro/VirtualScannerLink_20211103/`
- Duplicate/alternate Pro manuals and quick start guide:
  - `docs/manuals/pro/Raven_Scanner_Pro_User_Manual.docx_7.pdf`
  - `docs/manuals/pro/Pro_QuickStart_Guide_v6.pdf`
- Raven Desktop for Windows and a third-party scanning utility:
  - `downloads/software/Raven-Desktop-Setup.exe`
  - `downloads/software/naps2-7.5.1-win.exe`
- A README from the bundle describing installation order and usage:
  - `docs/support/READ ME FIRST.pdf`

These community-sourced artifacts are preserved here for convenience; they should be treated as historical/research copies rather than official distributions.
